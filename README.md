# 🧮 Calculator 

A simple and modern web calculator built with **HTML, CSS, and JavaScript**.

The project focuses on providing a clean user interface with reliable basic calculator functionality.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Percentage calculations
* 🔄 Positive/negative number toggle
* ⌫ Delete last character
* 🧹 Clear calculator
* ⚠️ Error handling
* 🔢 Input length protection
* 📱 Responsive interface

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* DOM API

No frameworks or external libraries are required.

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Open the project folder and launch `index.html` in your browser.

That's all — no installation or build process is required.
